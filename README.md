# 数学与人工智能学院官网原型

北京雁栖湖应用数学研究院（BIMSA）「数学与人工智能学院」官网前端原型。

## 设计方向

- 参考北京中关村学院官网 `https://www.bza.edu.cn/` 的高校官网信息层级与页面节奏：首屏、学院简介、科研学部、学院日历、学院资讯、重点展示与页脚。
- 品牌与文案均替换为数学与人工智能学院 / BIMSA 语境，不直接复用参考站品牌资产。
- 当前原型的两张校园照片直接引用 BIMSA 公共站点 URL，正式上线前建议下载到本项目对象存储/CDN，避免跨站依赖。
- 研究方向与活动信息参考 BIMSA 当前公开网站 `https://www.bimsa.cn/`；正式发布前仍应由学院核验。
- 当前为纯前端原型，无 CMS、数据库、用户系统与真实站内搜索后端。

## 本地运行

无需安装第三方依赖：

```bash
npm run dev
```

默认访问：`http://localhost:4173`

也可以直接打开 `index.html` 浏览静态页面。

## 页面结构与生成方式

所有 HTML 页面由 `tools/build_pages.py` 生成，页头、导航、搜索、移动端抽屉与页脚只维护一份：

```bash
python3 tools/build_pages.py
```

- 首页正文：`tools/home.html`
- 组织架构正文：`tools/org-structure.main.html`
- 其余二级页：`tools/build_pages.py` 中的 `PAGE_META`
- 导航栏目：`tools/build_pages.py` 中的 `NAV`

**不要直接修改根目录的 `*.html`**，改源文件后重新运行脚本。

## 视觉与交互（参考清华大学、求真书院主页）

- 深蓝 + 金色品牌色，衬线标题，「英文小标 + 中文大标 + 金色短线」的栏目标题
- 首屏全屏轮播（自动播放、进度条、悬停/聚焦暂停、键盘与滑动切换）+「快速探索」搜索条
- 学院资讯：大图焦点 + 日期列表联动切换，分类筛选
- 学术活动：海报式卡片横向滚动（拖拽、箭头、进度条、类型筛选）
- 科研方向：标签切换 + 生成式数学插图
- 师资力量横向卡片、人才培养入口、学院理念、雁栖湖线描页脚
- Mega 菜单、移动端手风琴抽屉、站内搜索（`/` 快捷键）、返回顶部进度环
- 图片加载失败时自动替换为品牌封面；支持 `prefers-reduced-motion`

## 维护约定

- **不要把内部文件放进仓库根目录。** GitHub Pages 会把整个仓库原样发布，`.docx` / `.xlsx` / `.pdf` 已加入 `.gitignore`。
- **人物照片**：放在 `assets/people/`，使用 WebP，短边约 320px（头像最大显示约 140px，2× 屏足够），单张控制在 40KB 以内。缺照片时不写 `<img>`，直接显示姓氏占位。
- 学院名称统一使用「北京雁栖湖应用数学研究院」，联系邮箱 `mathai@bimsa.cn`，均直接写在 HTML 中。
- 英文版尚未建设，暂不显示语言切换按钮。
