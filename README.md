# 数学与人工智能学院官网原型

北京雁栖湖应用数学研究院（BIMSA）「数学与人工智能学院」官网前端原型。

## 设计方向

- 参考北京中关村学院官网 `https://www.bza.edu.cn/` 的高校官网信息层级与页面节奏：首屏、学院简介、科研学部、学院日历、学院资讯、重点展示与页脚。
- 品牌与文案均替换为数学与人工智能学院 / BIMSA 语境，不直接复用参考站品牌资产。
- 当前原型的两张校园照片直接引用 BIMSA 公共站点 URL，正式上线前建议下载到本项目对象存储/CDN，避免跨站依赖。
- 研究方向与活动信息参考 BIMSA 当前公开网站 `https://www.bimsa.cn/`；正式发布前仍应由学院核验。
- 当前为纯前端原型，无 CMS、数据库、用户系统与真实站内搜索后端。

## 本地运行

无需安装第三方依赖：

```bash
npm run dev
```

默认访问：`http://localhost:4173`

也可以直接打开 `index.html` 浏览静态页面。

## 当前页面模块

- 响应式透明 / 吸顶导航
- 全屏校园 Hero
- 学院简介
- 三大科研方向
- 学生培养
- 学院日历
- 可筛选学院资讯
- 搜索覆盖层（跨页面检索栏目，并定位当前页匹配段落）
- 移动端抽屉导航
- 学院联系信息与外部 BIMSA 链接

## 维护约定

- **不要把内部文件放进仓库根目录。** GitHub Pages 会把整个仓库原样发布，`.docx` / `.xlsx` / `.pdf` 已加入 `.gitignore`。
- **人物照片**：放在 `assets/people/`，使用 WebP，短边约 320px（头像最大显示约 140px，2× 屏足够），单张控制在 40KB 以内。缺照片时不写 `<img>`，直接显示姓氏占位。
- 学院名称统一使用「北京雁栖湖应用数学研究院」，联系邮箱 `mathai@bimsa.cn`，均直接写在 HTML 中。
- 英文版尚未建设，暂不显示语言切换按钮。
