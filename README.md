# 数学与人工智能学院官网原型

北京应用数学研究院「数学与人工智能学院」官网前端原型。

## 设计方向

- 参考北京中关村学院官网 `https://www.bza.edu.cn/` 的高校官网信息层级与页面节奏：首屏、学院简介、科研学部、学院日历、学院资讯、重点展示与页脚。
- 品牌与文案均替换为数学与人工智能学院 / BIMSA 语境，不直接复用参考站品牌资产。
- 当前原型的两张校园照片直接引用 BIMSA 公共站点 URL，正式上线前建议下载到本项目对象存储/CDN，避免跨站依赖。
- 研究方向与活动信息参考 BIMSA 当前公开网站 `https://www.bimsa.cn/`；正式发布前仍应由学院核验。
- 当前为纯前端原型，无 CMS、数据库、用户系统与真实站内搜索后端。

## 本地运行

无需安装第三方依赖：

```bash
npm run dev
```

默认访问：`http://localhost:4173`

也可以直接打开 `index.html` 浏览静态页面。

## 当前页面模块

- 响应式透明 / 吸顶导航
- 全屏校园 Hero
- 学院简介
- 三大科研方向
- 学生培养
- 学院日历
- 可筛选学院资讯
- 搜索覆盖层
- 移动端抽屉导航
- 学院联系信息与外部 BIMSA 链接
